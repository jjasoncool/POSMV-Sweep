# 新版面實測：Simulator 分頁與正式程式精簡版面（2026-10-02）

- 環境：同 [2026-10-02-virtual-com-lifecycle.md](2026-10-02-virtual-com-lifecycle.md)；COM10↔COM11、COM12↔COM13，com0com 2.2.2.0。
- 程式版本：本報告同一批 commit 的 Debug 建置。
- 操作方式：同 [2026-10-02-gui-end-to-end.md](2026-10-02-gui-end-to-end.md)，以真實滑鼠輸入操作，再以 PrintWindow 截圖判讀。
- 範圍：版面決定 L1–L8，以及 R6（MBES 穩定上限預設改為 ±15°）。

## 步驟與結果

| # | 操作 | 結果 |

| 1 | 開啟 Simulator | 自動檢查並自測；「測試」頁顯示「✔ com0com 2.2.2.0 已安裝，虛擬 COM 已就緒，自測通過」；安裝與建立按鈕都沒有出現；大字顯示正式程式要選 COM11／COM12（38400 bps） |

## 發現並已修正的問題

1. **自動自測失敗**：檢查完成後立刻自測，但 Simulator 還開著上一份結果檔，所以刪不掉，畫面顯示「cannot remove result.txt」。改為讀完結果就關閉檔案。
2. **錯誤訊息亂碼**：MinGW 的 `std::system_category()` 以 ANSI 字碼頁回傳 Windows 錯誤訊息，在中文 Windows 的 GTK 畫面上變成亂碼。新增 `win32_error.hpp`，改以 UTF-8 顯示；COM 埠開啟失敗的訊息也一併改善。
3. **錯誤碼變成 0**：組錯誤訊息字串時，Windows 錯誤碼被覆蓋，顯示「操作順利完成（0）」，也因此判斷不出埠被佔用。改為失敗後先讀錯誤碼，再組訊息。
4. **「套用」按鈕跟著模式移動**：模式選單寬度隨選項改變，把按鈕往右推了約 56 px。改為固定寬度。
5. **非英文使用者名稱**：Simulator 狀態資料夾的路徑原本以 ANSI 解讀 GLib 的 UTF-8 路徑；已改正，但沒有在非英文帳號下實測。
