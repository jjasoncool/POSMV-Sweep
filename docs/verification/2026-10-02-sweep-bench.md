# 測試台實測：量測 Offset、固定 Offset 與收尾到 CENTER（2026-10-02）

- 環境：同 [2026-10-02-virtual-com-lifecycle.md](2026-10-02-virtual-com-lifecycle.md)；COM10↔COM11、COM12↔COM13 兩組配對，com0com 2.2.2.0，鮑率模擬開啟，38400 bps。
- 程式版本：以 `d203948` 加上之後提交為 `7c036fa`、`e2a674e` 的修改建置，`build/` 的 Debug 建置；當時還沒有固定 Offset 的雜訊門檻（見「發現的問題」）。
- 操作方式：同 [2026-10-02-gui-end-to-end.md](2026-10-02-gui-end-to-end.md)，以真實滑鼠輸入操作兩個程式，再以 PrintWindow 截圖判讀。
- 目的：確認 Proxy 實際加上的 Offset 與設定一致，而且不受船體 Roll 影響；並驗證逐筆轉送、兩種警告、固定 Offset 模式與收尾到 CENTER。

## 設定

| 程式 | 設定 |
|---|---|
| Simulator | TX COM10、RX COM13；25 Hz；正弦 Roll ±5°、週期 7 秒，模擬船體搖擺；Heave 寫入序號 |
| 正式程式 | 輸入 COM11、輸出 COM12；正弦 Sweep ±10°、Cycle 4 秒、先負；MBES 穩定上限 ±10°；擺動速度上限 10°/s；資料過期門檻 500 ms |

## 1. 量測 Offset

操作：正式程式連線，Simulator 開始測試，2 秒後開啟 Sweep，約 14 秒後截圖。

| 項目 | 結果 |
|---|---|
| 量測到的 Offset | 幅度 ±10.00°、週期 4.00 秒、中心 0.00°，與設定一致 |
| Simulator 收送 | 送出 449 筆，收到有效 449 筆，無效 0、垃圾 0、遺漏 0 |
| 延遲（送出到收到） | 平均 0.1 ms、p99 0.2 ms、最大 32.7 ms |
| 正式程式收送 | 收到 448 筆、送出 448 筆，無效 0、截斷 0、中斷 0 |
| 轉送延遲 | 平均 0.07 ms、最大 15.46 ms |
| 輸出間隔 | 平均 39.9 ms、最小 7.8 ms、最大 40.9 ms、p99 40.5 ms |
| 警告 | 「輸出 Roll 11.66° 超過 MBES 穩定上限 ±10.00°（累計 108 筆）」，以及「最大擺動速度超過設定上限」；畫面顯示最大擺動速度 15.7°/s |

判讀：

- 模擬船體以 ±5° 搖擺時，量測到的 Offset 仍是設定的 ±10°、4 秒，中心為 0，表示 Proxy 只在 Real Roll 上疊加 Offset，沒有混入船體的 Roll。
- 正式程式收到幾筆就送出幾筆，Simulator 沒有遺漏，符合逐筆轉送（[ADR 0001](../adr/0001-forward-each-frame-on-arrival.md)）。
- 延遲大多在 0.2 ms 以內，但出現過一次較大的延遲：端到端最大 32.7 ms，其中正式程式轉送最多 15.46 ms。最小輸出間隔 7.8 ms 約等於 40 − 32.2 ms，符合「單一筆延後、下一筆準時」的情形。之後的截圖中這兩個最大值都沒有再變，表示只發生在第一次截圖之前。原因還沒查明，留待 10 分鐘長測追蹤。
- 預設 Angle ±10° 等於預設的 MBES 穩定上限，只要船體有 Roll，接近峰值時就會超過上限；這次 448 筆中有 108 筆（24%）超過。警告如預期出現。

## 2. 固定 Offset 模式

操作：模式改為「固定 Offset（驗證用）」5.0°，按「套用 Sweep 設定」，1 秒後截圖正式程式，再過 21 秒截圖 Simulator（讓 20 秒的估算視窗只包含固定 Offset 的資料）。

| 項目 | 結果 |
|---|---|
| 正式程式 | 提示「設定已套用，Sweep 從 CENTER 重啟；offset 可能跳變」；Real −4.44°、Offset 5.00°、Output 0.56°；最大擺動速度 0.0°/s |
| 警告 | 改為「輸出 Roll 曾超過 MBES 穩定上限（累計 471 筆）」，不再有 ⚠ 標記 |
| 量測到的 Offset | 目前 5.00°、幅度 ±0.00°、中心 5.00°；但同時顯示「週期 0.63 秒」，見發現的問題 |
| 收送 | 正式程式收到 1983 筆、送出 1983 筆；Simulator 收到 2509 筆全部有效，遺漏 0 |

## 3. 收尾到 CENTER

操作：模式改回正弦，勾選「關閉與套用時收尾到 CENTER（不立即跳回 0）」，套用；3 秒後關閉 Sweep，約 0.2 秒與 2.7 秒後各截圖一次。

| 項目 | 結果 |
|---|---|
| 從固定 Offset 套用 | 立即生效：Offset 從 +5° 跳到 0，再從 CENTER 開始先負。收尾只沿著進行中的正弦走，固定 Offset 沒有 CENTER 可走，所以照設計直接切換 |
| 關閉 Sweep | Offset 沿正弦降到 CENTER 後停在 0.00°；Output 平順接回 Real Roll；放大趨勢圖也沒有垂直跳變 |
| 收送 | 收到與送出都是 3590 筆，無效 0 |

限制：關閉 Sweep 的時間點離下一個 CENTER 很近，第一次截圖時收尾已經完成。這次只能確認沒有跳變，沒有拍到「收尾中」的畫面；完整的收尾行為由 `test_proxy` 的規格測試涵蓋。

## 發現的問題

1. **固定 Offset 顯示假的週期**：浮點數雜訊（例如 7.34 − 2.34 不完全等於 5）讓估算以為 Offset 在中心線上下穿越，顯示「週期 0.63 秒」。已於同日修正（`e2a674e`）：幅度小於 TSS1 解析度的一半（0.005°）時視為固定值，不估算週期，並加入 `test_signal` 的規格測試。修正後還沒有用 GUI 複測。
2. **固定 Offset 的套用提示**：固定模式沒有 CENTER，提示卻寫「Sweep 從 CENTER 重啟」。用詞問題，尚未修改，併入版面調整。

## 未涵蓋

- Sweep 進行中按「套用」，等到下一個 CENTER 才切換：只有規格測試，GUI 未操作。
- 「收尾中」的畫面狀態，以及修正後的固定 Offset 顯示。
- 反轉方向、50／100 Hz、10 分鐘長測、故障注入。
- 實體 MBES：本報告只證明 Proxy 送出的 Roll 符合設定，不代表 MBES 的波束確實照此擺動；方向與正負號仍需現場以固定 Offset 確認。
