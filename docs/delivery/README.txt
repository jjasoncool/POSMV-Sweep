POSMV-Sweep 使用說明
====================

本套件含兩個程式，解壓縮後直接執行，不需要安裝：

  posmv-sweep.exe       正式程式：在 POS MV 與 MBES 之間轉送 TSS1 姿態資料，並可加上 Sweep
  posmv-simulator.exe   測試工具：在同一台電腦上模擬 POS MV，檢查正式程式的輸出

請保持資料夾完整；只複製 .exe 無法執行，它需要同一資料夾裡的 DLL。
系統需求：Windows 10 或 11（64 位元）。

注意：這是開發版。實體 Roll 的正負號與 Sweep 的實際擺動方向尚未在現場確認，
第一次接上儀器時，請先用「固定 Offset（驗證用）」模式確認方向。


一、正式程式（posmv-sweep.exe）
------------------------------

正式程式只需要兩個實體 COM 埠，不需要安裝任何驅動：
  輸入 COM：接 POS MV 的 TSS1 輸出
  輸出 COM：接 MBES 的姿態輸入
兩者不能是同一個埠。序列設定固定為 8N1、不使用流量控制。

1. 選擇輸入與輸出 COM、鮑率（須與 POS MV、MBES 一致），按「連線」。
   狀態顯示「運作中」表示正在轉送。
2. 「Sweep：OFF」時，輸出與輸入逐 byte 相同。
3. 設定模式、幅度與週期後按「套用」存檔；按藍色的 Sweep 按鈕開始，
   會採用畫面上的設定，從 CENTER 開始加上 Offset。再按一次關閉。
4. 「MBES 穩定上限」請依儀器設定（預設 ±10°）。輸出 Roll 超過上限時，
   數值與示意圖會變成橘色。
5. 輸入超過「過期門檻」沒有資料時，程式會暫停輸出並關閉 Sweep；
   資料恢復後 Sweep 維持關閉，需要時再手動開啟。

使用 USB 轉序列線時，建議在「裝置管理員」把轉接器的 Latency Timer 調成 1 ms，
讓轉送延遲小且穩定。


二、測試工具（posmv-simulator.exe）
---------------------------------

測試工具在本機建立兩組虛擬 COM 埠，讓兩個程式互相連線，
用來在沒有儀器的情況下確認正式程式的行為。

1. 開啟後會自動檢查測試環境。第一次使用時，依畫面按
   「安裝 com0com 驅動」與「建立虛擬 COM 埠」，Windows 會要求系統管理員權限。
   驅動安裝檔在 drivers\ 資料夾，程式會先檢查 SHA-256 再安裝；
   本程式不會關閉任何 Windows 安全機制。
2. 畫面會顯示正式程式要選的兩個 COM 與鮑率。先讓正式程式連線，
   再按「開始測試」。
3. 不再需要時，在「環境與進階」頁可以移除本程式建立的配對，
   或解除安裝本程式安裝的驅動。
